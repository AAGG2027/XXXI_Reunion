# XXXI Reunión de la AAGG

Sitio oficial de la XXXI Reunión de la Asociación Argentina de Geofísicos y Geólogos (AAGG).

📅 **Fechas:** 14–17 de septiembre de 2027  
📍 **Lugar:** Concordia, Entre Ríos, Argentina  

Este congreso reúne investigadores, profesionales y estudiantes para compartir avances en geociencias, hidrogeología y métodos geofísicos aplicados.
